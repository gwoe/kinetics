# Kinetics
Software snipplets for kinetics using Python and Mathematica
This repository contains IPython code for kinetic simulations and illustration. 
The contents have been developed in the course "Kinetics of Cellular Reactions" and elaborated for the textbook "Molecular Machines" (ISBN 978-3-032-26169-4)
The notebooks are intended to illustrate the effect of parameter changes on the outcome of biophysical and kinetic models. Originally, the code has been written in Wolfram Mathematica language, and most of the figures in the book are based on the output of my Mathematica notebooks. The code has been tested with Mathematica 12 and Wolfram 15 under MacOS X, a large number also with Mathematica 12 under Noobs on a Raspberry Pi4 computer. 
Because of the wide usage of the Python programming language, the code has been converted to IPython notebooks. The conversion has been aided by artificial intelligence. I have added explanations and optimized the code manually. The IPython notebooks have been tested under Python 3, jupyter 7 and JupyterLab 4.
